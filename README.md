# InfraSantaCruz 
📱 Rede social para a comunidade de Santa Cruz do Sul

⚠️ **Santa Cruz do Sul é uma cidade rica, mas com muitos problemas de infraestrutura**

Do centro da cidade até o interior dos bairros, todos temos reclamações:
- Essa estrada nunca vai ser asfaltada?
- Onde estão as rampas de acessibilidade?
- Por quê tem um buraco enorme na calçada?

**Se pensamos nessas questões e queremos contribuir para uma cidade melhor, por quê não criar uma comunidade para compartilhar estas pautas?**

🔗 Compartilhe os problemas da cidade para que todos vejam

🧑 Engaje com posts e comentários para compartilhar SUA OPINIÃO com as pessoas

👥 Trabalhem juntos para que os problemas de ninguém sejam esquecidos

## O que te aguarda
- Postagens com fotos, descrições detalhadas e localização geográfica
- Comentar, curtir, responder como formas de engajar a comunidade
- Feed interativo e infinito, inspirado nos aplicativos mais usados do mundo

## Documentação técnica
Requisitos de sistema: Android (Versão aqui) ou iOS (Versão aqui)
Métodos de login: Atualmente só é possível fazer com a conta Google.

## Limitações e o futuro
Atualmente a maior limitação é o investimento financeiro de manter uma aplicação serverless rodando.

Parte disso pode ser mitigado trocando por um servidor dedicado em uma máquina própria, mas ainda seria necessário usar serviços de cloud para push notifications e login social.
